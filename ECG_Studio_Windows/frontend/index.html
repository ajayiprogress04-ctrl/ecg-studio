User Guide · What happens to my files?

Your original recordings stay unchanged. Each run creates a new ECG_Studio folder inside the destination you choose. Each input has its own numbered subfolder, containing its six-hour CSV files. Completed outputs stay on your computer until you delete them.

Reads 100,000 rows per chunk. Invalid timestamps and non-numeric/missing signal values are discarded, as in your original script. The first valid timestamp starts the first six-hour window. A final partial window is kept. No resampling, filtering, sorting or timezone correction is added.

Expected format: comma-separated text with timestamp, ECG raw and ECG millivolt columns. Timestamps follow 2026-06-18 08:52:24.000. Output names and all six columns match the original Python workflow. Comments are not copied into output files. A header row can count as discarded.

Large recordings need free space for expanded CSV outputs. Admission checks estimate six times the input size plus a reserve; actual output size varies. Files run sequentially. Stop batch takes effect after the current chunk is written; the current incomplete output is removed, and earlier completed recordings remain.

Privacy & offline use

This application runs only on this computer at a local 127.0.0.1 address. It makes no external service requests, uploads no recordings and uses locally bundled fonts. No Render account, Vercel deployment, Python installation or internet connection is needed to process files.

Processing summaries may contain local filenames, output paths and row counts. They are saved in your selected batch folder. They contain no ECG sample values. Keep output folders and recordings out of public repositories.

Closing the browser tab does not stop the application. Use Close application, or return to the still-open launcher window. If you launch another copy, it opens a separate local session.
